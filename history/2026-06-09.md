# 2026-06-09 개발 이력: Phase 1 & Phase 2 완료 (로컬 암호화 MVP & 통계 대시보드)

---

## 📌 1. Phase 1: 암호화 기반 로컬 MVP 구축

기존 메모리 기반 정적 플래너에서 데이터 영구 보존 및 안전한 백업이 가능한 로컬 암호화 웹 애플리케이션으로 업그레이드하였습니다.

### 🔒 강력한 로컬 암호화 (Web Crypto API)
* 앱 최초 진입 시 마스터 암호화 키 작성을 위한 **PIN 모달 창** 적용
* 4자리 이상 PIN 기반 AES-GCM 알고리즘을 사용한 브라우저 단 암호화 저장을 구현

### 💾 일일 데이터 영구 저장 (IndexedDB)
* 할 일(Task) 추가/수정/완료 상태 변경 시 즉시 저장
* 타임박스(Timebox) 조작 및 메모/피드백 입력 시 자동 저장

### 📅 날짜 내비게이션 위젯
* 상단 중앙 날짜 이동 위젯(`< 2023-10-27 >`)을 통한 일자별 데이터 전환 기능 추가

### 🛡️ 데이터 백업 & 복원 (JSON)
* 수동 파일 백업 및 복원 기능 추가 (JSON 파일 내 암호화 데이터 내보내기)
* 유효한 PIN 로그인 상태에서만 복호화 및 복원이 가능하도록 보안 처리

---

## 📊 2. Phase 2: 로컬 데이터 기반 통계 대시보드 구축

### 📈 통계 대시보드 UI 및 차트
* **업무 완료율**: 선택 기간 내 전체 할 일 중 완료('V')된 비중 도넛 차트 시각화
* **타임박스 실행 현황**: 계획(Plan) 시간 대비 실제 수행(Exec) 시간 누적 비교 바 차트

### 🔐 로컬 데이터 가공 및 보안
* 외부 서버 전송 없이 **100% 브라우저 내부**에서 데이터 복호화 및 계산 처리
* 최근 7일, 30일, 90일, 전체 기간 동적 필터링 기능 지원

---

## 🧪 3. 검증 (Verification)

1. **PIN 및 저장 테스트**: PIN 입력 후 데이터 작성 시 IndexedDB에 무사히 반영됨을 확인.
2. **백업 및 복원 테스트**:
   * JSON 백업 파일 다운로드 및 브라우저 스토리지를 비운 후 복원 테스트 완료.
   * 엉뚱한 PIN 상태에서는 복호화 실패 처리됨을 검증.
3. **통계 차트 연동 테스트**: 일자별 타임박스/할 일 데이터 수정 시 대시보드에 즉각 반영됨을 확인.
