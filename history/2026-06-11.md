# 2026-06-11 개발 이력: 비즈니스 모델 및 요금제 기획 (Business Strategy)

---

## 📌 1. 3단계 비즈니스 모델 기획 (Zero Server Cost 모델)

개인 사용자를 타겟으로 중앙 서버 유지비 없이 실용적인 수익을 창출할 수 있는 3단계 비즈니스 모델을 정립하였습니다.

### 🟢 1. Free (무료 버전)
* **가격**: 0원
* **기능**: 할 일 및 타임박싱 기본 작성, 로컬 암호화 저장, 최근 7일 통계 대시보드
* **제한**: **데이터 백업/복원 하루 1회 제한**

### 🔵 2. Essential (에센셜 버전)
* **가격**: 4,900원 ($3.99) 평생 1회 결제
* **기능**: **수동 데이터 백업/복원 무제한**, 최근 **30일** 통계 대시보드 조회
* **목적**: 1회 결제로 백업 제한을 해제하고 즉각적인 현금 흐름 창출

### 🟣 3. Unlimited (언리미티드 버전 - 구독)
* **가격**: 월 3,900원
* **기능**: 사용자의 개인 소셜 구글 드라이브/클라우드를 활용한 **무서버 클라우드 자동 동기화**, 전체 기간 통계 조회, '나의 사명 및 비전' 장기 목표 관리 해금

## 🛡️ 2. 라이선스 방식의 한계와 방어 전략 수립

1. **클라이언트 라이선스 우회 위험 분석**:
   * DevTools 콘솔을 통한 스토리지 상태 조작 및 JS 코드 리버스 엔지니어링 가능성 식별.
2. **현실적인 방어책 수립**:
   * 클라우드 DB(Firebase Firestore) 기반 API 검증을 적용하여 가짜 라이선스 키 등록 차단.
   * 최초 결제 인증 시 브라우저 고유 UUID를 Firestore에 귀속시켜 라이선스 키 중복 공유 차단.
   * 무단 복제가 불가능한 OAuth 기반 클라우드 동기화(Unlimited)로 사용자를 유도하는 전략 확립.
